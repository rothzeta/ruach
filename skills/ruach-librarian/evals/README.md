# Librarian behavioral evaluation packet

These corpora are synthetic. Prepare a fresh isolated copy for each subject; never run upkeep on a real consumer mailbox. The Implementer prepares fixtures but does not perform or self-grade the subject run.

Give the subject only `skills/ruach-librarian/SKILL.md` and the chosen `cases/<case>/task.md` with that case's `cases/<case>/corpus/` directory. Use the task and raw corpus; supply no intended answer, prior outcome or suspected failure. Do not expose `expected/`, this packet README, implementation handoffs or other evaluator outputs. The evaluator's harness should whitelist those input paths when possible.

After the blind worker returns its report and edited corpus, a separate grading assignment may read [expected/rubric.md](expected/rubric.md). Preserve original inputs and subject outputs separately. Judge observable preserved knowledge, authority and evidence, not exact generated phrasing. Structural/link/frontmatter checks do not prove that Librarian decisions are sound.
