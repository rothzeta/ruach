# Consumer guidance (probehub)

- The task record is `record.md`. `inputs/`, `observations/`, `policy/`, `logs/` and the history in `repo/` are read-only evidence.
- Allowed edits: `record.md` and files under `drafts/`.
- A register exemption is scoped to the environment it names. A recurrence outside that environment is not covered by it.
- Preserve the failing evidence and the environment each run used; do not invent a cause for a recurrence.
