# Project documentation guide

All names, revisions and logs in this corpus are synthetic. `index.md` is the entry point. Pages in `knowledge/` summarize current project knowledge and link to evidence. `decisions/log.md` is the decision record of the project owner, dana; only dana edits it. Worker reports are in `sources/` and raw CI logs in `sources/ci/`. Revision labels `ash-rN` increase by one with each merged change. Use relative Markdown links with explicit `.md` extensions.
