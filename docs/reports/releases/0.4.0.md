# Ruach 0.4.0: OpenCode v2 launch support

OpenCode is now an enabled Ruach launch adapter for v2.1.4+ within major 2. Previously every OpenCode preparation returned `unsupported_adapter`. Preparation now reads native state through an owned standalone server, verifies the exact requested model/variant and composed settings, and prepares an interactive standalone worker. The shared service is preserved.

The selected primary agent keeps its system text, native permissions and other configuration. Canonical role instructions and private canonical skill paths are additive. Workers deny discovered workflow IDs/aliases and canonical workflow names; Coordinators retain existing native workflow access. The adapter preserves inline JSONC and caller-selected OpenCode/XDG config roots, with private values withheld from its result. Models are never substituted. Unsupported versions, missing/disabled models, unoffered variants and conflicting managed settings fail before creating launch resources.

Use the skill's direct launcher with `--kind opencode --model provider/model --permissions inherit`; an explicit effort must be an offered model variant, while omitted effort or `auto` uses the default. Ruach's development route wrapper takes declared routes rather than `--kind`; the README gives the complete direct source command. OpenCode `--auto` is not an approval reviewer, so portable `auto-review` remains unsupported. No routing preference or global harness setting was changed.

No credential files or raw live configuration are included in this report.

## Limits and release scope

The native smoke proves transport and config composition using fixture responses. It does not establish model reasoning quality, entitlement, a real consumer task, or the earlier R1/R3 behavioral criteria. Live permission-classifier behavior is unclaimed; OpenCode inherits native permissions and has no Ruach auto-review mapping. Known workflow filtering is not a filesystem sandbox or protection against later undeclared plugin mutations.

This release also includes the previously consolidated R6/R7 guidance, offline wave-2 packets and multi-machine council documentation listed in the changelog. Remaining wave-2 guides/specimens/startup tests and complete independent batch acceptance remain on the roadmap. Earlier release tags stay immutable. This report records source preparation and verification; final commit, annotated tag and remote publication identities are returned after they exist.
