## Minimal design and reviewed usage definitions

Use one offline TypeScript/Bun CLI reading only explicitly supplied files through a private manifest. No recursive home scan, session launcher, API billing lookup, watcher, database or benchmark runner. Keep provider-format parsing and aggregation in the small script unless real complexity demonstrates a need to split it. Prefer adapting an actually supplied historical implementation; if it appears later, identify its location/license/version and request bounded scope before treating it as the predecessor. Do not quietly create a second editable analyzer.

M-U0 freezes `m1-usage-v1` definitions and representative synthetic format fixtures with an independent Reviewer. Actual native versioned sample/format evidence, supplied under explicit read/privacy authority, is required to call a parser supported for that native format. Unsupported formats remain named, unavailable coverage. Claude/Codex are the initial requirements; Gemini/agy only when actual versioned logs are available and justified, never through guessed conversion or automatic harness substitution. Synthetic fixtures establish arithmetic/transport, not actual native completeness.

Distinguish blocking waits/wakes from nonblocking polling and timed pauses. Proposed CLI after implementation: `bun scripts/session-usage.ts --manifest <private-manifest.json> --out <fresh-absolute-private-json>` and `--help`. Manifest is a small reviewed file listing run/worker pseudonyms, explicit source paths/format versions, selection window or run membership, required/optional sources and recorded phase/route references. It is private, outside Git; do not add a broad shared schema or change handoff/harness-eval v1. Minimal result has definition ID/digest, analyzed input-format versions, run/worker references, inclusion/coverage reasons, counts/token categories/time evidence, known sums and gaps. Detailed identity/source mapping stays in a separate private receipt.

CLI never executes text from a transcript/manifest. Reject invalid manifest, unknown definition, unsafe output/overwrite, symlink/special-file input and self-overlapping output before writing. Read only manifest-allowed regular files with declared byte/line/time bounds. New outputs outside the repository/input trees/Git metadata are created exclusively with private mode; diagnostics use source aliases/line numbers and never raw text, IDs, paths or environment dumps. Exit 0 means configured analysis completed (coverage fields still govern interpretation); exit 1 means partial/failed required analysis with preserved structured gaps; exit 2 means invalid input/setup. Retain malformed/truncated/unsupported source counts; never silently produce a complete-looking sum. Reviewer approves explicit required-versus-optional semantics and public-CLI privacy controls.
