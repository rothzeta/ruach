# Council member assignment

Copy and fill this alongside the [assignment specimen](assignment-specimen.md). This is a member brief, not a workflow. The Coordinator owns access isolation, rounds and scheduling. Placeholders grant no authority and prefill no result.

```text
Role: <installed Scout, Architect or consumer-declared read-only domain role>.
Task/work/member/round/version: <IDs>. Coordinator: <one owner ID>.
Outcome: evidence-backed advice on <exact bounded question/version>.
Owner decisions: <exact words, source/date/IDs, limits and supersession>.
Source/resource baseline: <resolved existing SHA and input digests>.
Workspace/branch: <assigned path and checked unused branch>.
Roster/expertise/routes: <named members>. Mode: <manual one round |
  automatic exact N total including first | explicitly up-to N, stop when stable>.
Completed/remaining rounds: <actual counts, not submission attempts>.
Inputs/read scope: <explicit sources>. Runtime/network probes: <allowed or none>.
Round one: peer reports/answers/synthesis excluded by <actual boundary>;
  control evidence <required input/resource access and peer-marker exclusion>.
Later round only: <actual closed report IDs/versions>, <listed new evidence>.
Own only <member report> and <unchanged assignment if required>.
Protected: all product source/tests/configuration, task record and peer reports.
Return position, evidence/limits, assumptions and authority; in later rounds,
  accepted/rejected attributed arguments and reasons, changes since prior position,
  supported minority objections and resolving evidence/owner questions.
Report missing access or evidence honestly. Do not invent peer answers.
Budget/capabilities: <time/actions, tools, allowed escalation requests>.
Verification: <named evidence reads, owned links/whitespace, exact handoff
  validator command with --repo and bound>. No product tests/probes unless assigned.
Scope amendment: report concrete need to Coordinator; do not broaden.
Handoff: <durable report>, canonical ruach-handoff leading YAML;
  <commit rule>; return creating SHA externally after commit.
No product edits, peer coordination, workflow loading, owner adoption or delivery.
```

For an optional Architect synthesis assignment, substitute exact closed reports as inputs and one synthesis report as output. Request propositions, evidence, authors' accepted/rejected arguments and reasons, changed assumptions, retained supported objections, resolving evidence, recommendation and separate owner-adoption status. Give no dispatch/waiting authority. Manual pause and session release belong to the Coordinator; members need not remain alive for artifact-based resumption.
